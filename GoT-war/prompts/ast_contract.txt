Structural expressions are JSON trees. Leaves: {"ref":"parent_id"}, {"noise":"background_id"}, {"const":0} (or 1, number, category string). Operations: {"op":"and","args":[...]} with and/or (2-8 args), not (1), xor (2), if (condition,then,else), eq/ne/lt/le/gt/ge (2), add/sub/mul/div/min/max, clip(value,low,high), sigmoid(value). No Python, no natural-language expressions. Every referenced state must be a declared parent; every background input must be declared. DAG only. All declared parents must actively affect their child's equation for some valid input. Conditional branches must have compatible types. Fixed mechanisms must reproduce factual observations and remain valid under interventions. An unknown mechanism must be marked as an assumption rather than memory-derived evidence. Provide operational definitions and explicit reference input meaning; no arbitrary probabilities.
For example, a conjunction is {"op":"and","args":[{"ref":"a"},{"op":"not","args":[{"ref":"b"}]}]}. Every nested argument is an object. Raw strings like "a" and raw numbers like 0 are invalid arguments; wrap references and constants in their explicit leaf objects.
