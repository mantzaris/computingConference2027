# GoT-war

A research prototype that synthesizes source-linked structural equations, executes frozen interventions, and attributes a model/reference contrast to a fixed set of overlapping paths. All literary variables, parent sets, equations, evidence assessments, and explanations are generated by the local GPU model. Source selection and outcome definitions are declared research choices.

The measured primary experiment is complete: 60 generating SCMs, 96 text records, four paired methods and two ablations. **This campaign does not establish source-valid literary explanations.** The retained application networks have 10, 8 and 3 nodes, only one distinct functional model per case, and zero weakest-link support on every retained path. All final generated explanations fail the automatic trace audit and are withheld. The anonymous manuscript is an evidence-backed scaffold reporting these failures alongside the controlled results.

Start with [measured results](results/RESULTS.md), the [handoff](docs/HANDOFF.md), or the [anonymous manuscript PDF](paper/manuscript.pdf). Exact runtime, GPU usage, seed-subset completion and failure counts are recorded in those artifacts and `results/usage.json`.

## Entry points

Run from this directory (do not create another nested `GoT-war`):

```sh
python3 scripts/reproduction.py
PYTHONPATH=src python3 -m got_war.cli status
PYTHONPATH=src python3 -m got_war.cli environment
mkdir -p .cache
PYTHONPATH=src python3 -m pytest -q tests --basetemp=.cache/pytest
PYTHONPATH=src python3 -m got_war.cli evaluate
PYTHONPATH=src python3 -m got_war.cli figures
```

For a configured GPU host with the frozen checkpoint and a project loopback inference endpoint:

```sh
PYTHONPATH=src .venv/bin/python -m got_war.cli pilot
PYTHONPATH=src .venv/bin/python -m got_war.cli run
PYTHONPATH=src .venv/bin/python -m got_war.cli resume
```

`run`/`resume` finish missing controlled cases and application alternatives before analysis. A completed case is not generated again. Request caches include model revision, prompt/evidence hashes, seed and decoding settings; failed responses are also retained. Deadline guards reject new heavy jobs after hour 20 and reserve five hours for analysis and recovery. An expired campaign can still be analyzed, but cannot silently start new GPU work. A future campaign needs an explicitly authorized new budget file.

The final construction protocol is recorded in `configs/application_protocol.json`. Historical recovery scripts are preserved for audit, not a request to repeat every failed development phase. Offline regeneration is described in [REPRODUCIBILITY.md](docs/REPRODUCIBILITY.md); it does not require an active GPU service.

The execution uses `scripts/campaign.py` to start separate, registered benchmark and application workers after the measured pilot gate. `scripts/autosync.py` synchronizes results every 20 minutes over authenticated SSH. Connection details belong in the ignored `.private/transport.json`, never in manuscript or reports. This transport supports RunPod's shell-only SSH route without SCP/SFTP.

## Data and reproducibility

`data/manifests/sources.json` records URLs, access times, continuity, source type, hashes and license notes. Only television episode Plot sections are acquired. Raw text and private source packets are excluded from git. Reacquire with `corpus`, then compare hashes to the frozen manifests; upstream edits can prevent an exact match. Stable passage offsets use normalized plot text, not HTML byte positions. Source-packet membership and hashes are public.

The 60 generating SCMs, gold metadata and 96 deterministic text variants restore to `benchmark/cases.jsonl` from the compact `results/reproduction.tar.gz`. The archive also retains all 120 controlled records (including failed attempts), four final application records, paired baselines, final audits and usage metadata. Gold programs and labels never enter inference prompts. Development, calibration and test splits are grouped by generating SCM. All original model replies, including earlier application failures, remain in the ignored local run archive. Private prompt snapshots can reconstruct exact requests from frozen corpus text; only hashes are released to avoid distributing complete source packets.

## Scientific interpretation

Support scores concern evidence; structural influence comes from executing equations. Neither is a calibrated probability of war. Application results use fixed factual background states and assumed mechanisms; plausible alternatives and reference changes expose their sensitivity. Synthetic counterfactual accuracy establishes controlled reasoning behavior, not literary causal identification. Event citations verify exact traceability, not independent entailment or the truth of a character's report.

The path game activates the **union** of selected edges once. Inactive focused edges deliver explicit reference inputs to child mechanisms; other edges remain active. Shared edges can enable recombined routes. Contributions add to the declared model/reference contrast and can be negative. They are not isolated natural path effects or shares of objective historical responsibility.

The application corpus substitutes the northern campaign against Bolton rule for Robert's Rebellion because accessible onset evidence was insufficient. See `docs/DECISIONS.md` for the corpus gate and scope definitions.
