# Scientific decisions and deviations

The campaign began at 2026-10-12 04:39:58 UTC. Its immutable hard deadline is 2026-10-13 04:39:58 UTC. The source continuity is HBO television only.

## Corpus gate

Accessible episode plot summaries are secondary sources, not episode transcripts or independently corroborated witnesses. Only Plot sections are ingested; production sections discussing the novels are excluded. HBO's synopsis and the television wiki failed initial access checks. Raw text is private and excluded from git; normalized-text hashes, passage offsets, stable segment identifiers, and acquisition instructions are released.

The initial 30-page scan found 11 passages mentioning rebellion, Lyanna, Aerys, or Rhaegar. Most concern later revelations, the Greyjoy rebellion, or aftermath. They do not establish enough onset mechanisms for a meaningful ten-node model of Robert's Rebellion. We replace this provisional case with the northern campaign against Bolton rule, covering coalition formation and sustained conflict rather than calling one battle a war. This is an evidence-availability decision made before model generation. No cause, parent set, or equation was supplied for any application.

Outcome definitions, actor scope, horizons, lexical retrieval policy, and benchmark split are frozen in configs/experiment.json before main inference. Search terms locate evidence; they do not prescribe mechanisms. Source support for an event is distinct from support for a counterfactual equation.

## Controlled benchmark

Sixty independent generated SCMs are balanced across sizes 12/18/24 and complete/incomplete narratives, with 12 development, 12 calibration, and 36 test SCMs. Both deterministic text variants of a test SCM remain together. The renderer preserves every specified mechanism by construction. This is automated consistency, not human validation. Renaming was not needed for the first deterministic paraphrase/reordering variant.

Incomplete records deliberately omit a local mechanism. All deterministic binary truth tables over the missing rule's two declared parents are enumerated, retaining factual compatibility and active dependence. We do not score every alternative against a single hidden point outcome. B2 executes one accepted candidate; P independently enumerates this same generic rule class using only its extracted graph and factual observations. Generation receives narrative text and questions, never gold ASTs or query labels. Questions, paths, and text variants are not independent experimental units.

Evidence weights are display/retrieval support scores. No probabilistic calibration or fitted narrative probabilities are claimed. All application attribution uses stated factual background scenarios unless a justified distribution is available. Unsupported coefficients are assumptions, not estimates.

## Application construction revision

The initial free-JSON blueprint protocol failed on oversized outputs, disconnected event summaries, and/or short-span citation constraints. Those artifacts are archived as `application_v1`; failures are not removed from the inference log. A second structured-schema candidate protocol fixes the output identifier `W` to the predeclared question, bounds node/field lengths, and validates types, ancestry, temporal order and exact quotations. It supplies no literary causes, edges or equations. Each revised artifact still permits at most two diagnostic repairs. This is a disclosed development revision of application construction, not an untouched literary test set or evidence that every proposed mechanism is true. The controlled experiment prompts remain frozen after the synthetic pilot.

The pilot's cached summary originally described prefill as unavailable in a non-streaming call, but the actual request implementation used streaming. Treat per-request `time_to_first_content_seconds` and `decode_tokens_per_second` as authoritative. Time to first content includes scheduling and transport overhead; it is not an isolated kernel prefill measurement.

## Construction granularity

Monolithic blueprints combined variable typing, source selection, temporal placement, graph topology and short quotations in one long response. Failures can cascade across these independent fields, and schema-constrained decoding measured much slower than the pilot. A modular fallback separates variable discovery, individual type validation, dependency discovery and passage-span audit. Every dependency remains LLM-generated. Each artifact has at most two diagnostic repairs; each failure and protocol revision is retained. The fallback does not alter the frozen controlled experiment prompts or consult test outcomes. Accepted prior models are preserved rather than replaced for a better-looking result.

The controlled benchmark tests reconstruction of explicitly named station variables and mechanisms. It does not independently validate open-ended discovery of literary concepts. Its generation packaging differs from modular application construction; this is a limitation of transfer, not an unreported end-to-end accuracy claim.

The modular discovery responses sometimes designated the outcome by status rather than the requested identifier. Identifiers are normalized before graph discovery without changing variable meanings; an ambiguous designation is resolved by the GPU model. Source-ID validation was moved from the type checker to the citation selector, which can inspect the entire frozen packet. Generated chronology corrections are retained with the dependency proposal. These are disclosed application-development changes, not post-hoc edits to a desired causal graph. All original proposals and failed repairs remain available.

Before final evaluation, a scoring bug was corrected: a missing response or generation failure no longer earns uncertainty-handling credit. Only an explicit returned abstention or the complete compatible set can earn that credit. This changes evaluation bookkeeping, not inference prompts or held-out model selection.

## Source-semantic gate

The first formally valid modular graph primarily chained chronological events and its source-span audit missed actor/action mismatches. Formal executability alone was therefore inadequate for selecting principal application figures. A disclosed semantic development gate now asks the GPU model to check actor, action, object, report status and story time against the frozen packet, then generate direct mechanism proposals separately for each child before global DAG reconciliation. Corrections, omitted variables and mechanism rationales are retained. Earlier candidates remain in `application_v3`; this revision does not erase their failures or change the controlled benchmark. The audit uses the same model and remains subject to independent review. No researcher-written literary edge or rule is substituted.

A mechanism-packaging bug raised some malformed-equation diagnostics before the bounded repair loop. Root background declarations and immutable variable contracts now enter validation together with the generated expressions, so these failures receive the same maximum of two repairs. No extra internal residual is introduced to force factual agreement.

## Reasoning-enabled application review

The first source-semantic protocol still returned non-contiguous or punctuation-altered quotations despite two repairs, causing all three cases to fail its literal gate. Those failures are archived in `application_v4`. A bounded follow-up enables the same Qwen model's reasoning mode for source and mechanism review, retaining all thinking tokens in the raw completion and compute budget. Token counts use the cached frozen tokenizer to leave room within 8,192 tokens. The exact-span criterion is retained; no model paraphrase is relabeled as a source quotation. Controlled benchmark requests remain in their original non-thinking configuration. This is application-development work, not an independent model comparison.

The literal audit exposed punctuation-only mismatches (for example, quote marks and a generated sentence-final period) and explicit ellipses. A conservative locator now copies an existing contiguous lexical sequence from the model-selected source paragraph, preserving actual source punctuation. An ellipsis may yield one existing fragment; fragments are never joined into a fabricated quote. Synonyms, inserted words and noncontiguous token matches are rejected. Original generated quotations, raw exact-match status, alignment method and prior failed artifacts are retained. This normalization supplies navigation offsets, not proof of semantic entailment, and does not edit the event definitions or causal graph.

For model quotations that are paraphrases, a separate lexical locator can return a short, source-exact **navigation excerpt** from the selected paragraph. It cannot certify support. Such records retain the invalid generated quotation, explicitly mark entailment review required, and downgrade the event assessment to partial. This differs from punctuation alignment and is labeled in each source record. It avoids publishing fabricated quotations while allowing a source-linked hypothesis to remain inspectable. No passage, causal edge, or event meaning is invented by the locator. Source claims still require independent review.

Generated temporal numbers mixed relative ordinal ranks with season/episode codes. A separate model stage now identifies story-event episode IDs (or explicitly unknown time); deterministic encoding places those IDs in one numeric unit. This fixes representation, not a desired causal ordering. Retrospective reports remain distinguished from reported events, and uncertain timing is retained as unknown. Obsolete dependency proposals are archived under `prior_time_units`; only the project application worker was checkpointed for this correction. Resumption keeps the most recent bounded semantic repair instead of reviving an earlier rejected draft because a formatting check changed. No manually authored dependency is supplied.

Long graph-reconciliation reasoning exhausted output caps before producing JSON. The reconciliation prompt now reports all detected structural issues together and omits duplicate long rationale text; this bounded formatting stage uses JSON mode without thinking. Source/mechanism discovery retains reasoning mode. This is separate from the unchanged controlled protocol.

Whole-model equation repairs repeatedly referenced undeclared variables. The application now generates one mechanism per artifact with named formal input slots (`P0`, `P1`, ...) bound mechanically to its previously discovered parents. The LLM still chooses the entire expression and its assumptions; the binding operation supplies no causal rule. Each local artifact has at most two repairs and is checked for typing, bounds, factual compatibility and active dependence before the complete SCM is checked again. Previous failed whole-model equations are preserved. Repaired expression descriptions are rendered from the actual AST, with prior free-form wording retained separately.

Two implementation defects were exposed in the final application pass. Sparse graph-repair responses were replacing the entire parents mapping, erasing unchanged generated relationships; they now patch that mapping, with removals controlled only by an explicit drop list. Existing repair outputs are replayed rather than regenerated for this parser correction. Local equation diagnostics also lacked the concrete failing input/output row, and the prompt omitted event time. Both are now explicit, so a model cannot silently substitute a later character state for the recorded target state. Earlier failed generations remain archived. Application development involved multiple disclosed protocol revisions; the two-repair cap applies to each artifact within its recorded protocol, not to the entire development campaign. It must not be reported as only three total attempts per literary case.

## Source-first inventory revision

The repaired v5 construction still produced no accepted complete application SCM. Its variable inventory included actor/action errors and irrelevant events; global graph repair could not consistently reconcile it. The v6 development revision starts from smaller source chunks, extracts atomic claims, and performs a same-model entailment audit before selecting a causal subgraph from the broader inventory. Partial and unsupported inventory events are excluded. Context outside the outcome ancestry is preserved in the inventory rather than connected merely to satisfy a node count. Every substantive graph relation and local expression remains GPU-model generated. Root variables use an explicit background-identity contract; nonroot equations retain the active-parent and factual-compatibility checks, with reasoning enabled. All v5 artifacts remain archived. This is a further disclosed development revision and supplies no evidence of untouched application test performance. Controlled prompts, source packets, outcome questions and test splits remain unchanged.

An invalid typed state or quotation initially rejected an entire fact-extraction batch. Candidate admission now operates at the claim level: malformed claims are recorded in `fact_rejections_*.json`, while valid claims can proceed to semantic review. Existing failed batch responses are replayed through this filter without generating a replacement story fact or relaxing any retained-claim check. A case still fails if fewer than ten substantive outcome ancestors remain. Nonbinary proposals with invalid domains are rejected, so the distribution of retained state types is subject to this selection effect.

The source-first graph response exceeded its output cap when topology and long link explanations were serialized together. Its compact graph artifact now returns only dependencies, outcome timing/citations and short limitations; the separate equation-aware evidence stage supplies edge mechanism rationales. The model selects the outcome event episode from the frozen question, so a later corpus horizon does not automatically move an earlier outcome forward in time. Prior truncated outputs remain recorded.

A Boolean event missing only its comparison value can use an explicitly declared generic reference: the complement of its observed state, with presence/absence wording and provenance attached. This is a reference-scenario assumption, not an extracted event, a generated equation, or a topic-specific causal rule. Existing nonmissing model-proposed references are retained; malformed nonbinary domains are still rejected. Domain-endpoint and factual-reference sensitivity remain separate outputs.

## Incremental graph discovery

Global graph generations still confused episode/paragraph identifiers, referenced absent variables and proposed mutually inconsistent dependencies. A v7 graph-construction development arm reuses the source-audited inventory but asks the LLM first for the outcome assessment endpoint and an ordered relevant event subset, then for each child's direct parents among eligible earlier states. The model supplies within-episode ordering, each relation and a source-linked mechanism rationale. Restricting eligible parents ensures acyclicity and blocks future-state references; it supplies no story edge. Unused context is pruned after graph construction, and fewer than ten outcome ancestors is reported as a failure rather than repaired by invented links. This materially different decomposition has its own bounded per-child artifacts. Earlier global candidates and all protocol compute remain in the audit trail. Application development is exploratory; no untouched literary test accuracy is asserted.

The generated Five Kings assessment frame incorrectly treated the later documentary horizon as the endpoint of the primary outcome. Before any accepted application SCM, `configs/outcome_endpoints.json` made the dates already present in the research questions explicit: season 1 episode 10 for the primary Stark/Lannister conflict, season 6 episode 9 for the northern campaign, and season 8 episode 5 for conquest continuation. Later Five Kings claims remain documentary context and cannot become causes of the earlier outcome. This clarifies researcher-supplied target metadata without supplying any explanatory variable, edge or rule; the frozen question text and source packet remain unchanged. The original generated timeframe is retained as a failure of scope interpretation.

The first incremental Five Kings graph retained nine outcome ancestors: structurally meaningful, but one below the principal-figure size target. The node-count target is now reported separately from formal validity rather than discarding a useful executable smaller model or adding filler. Before final construction, source-exact events rejected only for malformed categorical/value fields receive a bounded GPU-generated state-schema repair. This changes no event meaning or source passage and supplies no parent or equation; the next source audit sees the repaired schema. Smaller retained models, if any, must be reported as failing the ten-node figure target.

## Bounded coverage review and final numerical refinement

After accepted models contained fewer than ten outcome ancestors, one source-coverage review was scheduled per undersized schema. Its prompt requests at most four documented missing events, supplies no desired graph or node quota, and permits an empty result. Proposed additions receive the ordinary full-paragraph event audit and fresh generated dependency selection. An untraceable claim is rejected individually, with its original generated quotation retained. Only one enrichment pass is allowed. The larger formally valid outcome-ancestor schema is selected if available; otherwise the initial accepted schema remains principal. This selection criterion concerns documented explanatory coverage, not counterfactual scores. Both construction histories are retained. It cannot establish that the larger graph is causally identified.

Initial mechanism generations can be functionally identical. Later alternatives now see prior accepted expressions for the same local input slots and are asked for a different defensible interpretation only where the evidence permits one. Repetition remains legitimate and is counted separately from distinct function signatures. The researcher does not supply a replacement interaction, causal reason, or equation.

Application games with at most eight paths receive exact coalition enumeration in the final numerical pass. Initial sampled attributions are preserved, enabling a direct check of Monte Carlo approximation. Benchmark attribution settings remain frozen. This refinement changes no graph, expression, or background state. Final application questions include up to twelve canonical single-node and then paired reference interventions, plus four factual/structural questions for matched text and graph baselines.

A model assessment occasionally assigns an edge both an unsupported status and a positive numeric evidence score. The final application display conservatively uses zero for unsupported/unassessed mechanisms and retains the original scalar and its ranking sensitivity. This is a disclosed evidence-policy correction, not a change to structural influence or a tuned benchmark result. Final source critique checks time, duplicate events and reference semantics separately from formal program validity; any adverse findings remain visible rather than being silently edited into a preferred story.

## Outcome-stage retrieval correction

Inspection of the conquest candidate exposed an input omission: before W received its occurrence citations, node-centered retrieval could fill the child-parent prompt with earlier-event paragraphs and omit the actual endpoint passages. The corrected W-parent stage receives the complete frozen packet. The relevance-order prompt also warns against selecting a chronological prefix, and its artifact key now includes the whole prompt. This supplies evidence and fixes cache invalidation; it does not supply a literary cause or desired connection. Prior graphs remain in `application_before_outcome_packet_fix`. The corrected protocol is selected regardless of whether its graph is larger or scores differently. All three primary schemas run before optional additional mechanisms. Local-equation artifacts now also validate a full prompt contract hash before reuse, preventing changed parent meanings from reinterpreting old formal input slots.

## Audit parsing and observed source-grounding discrepancy

Final source-review responses sometimes included unsolicited node IDs, misplaced parent-order mappings, or flags naming a node that was not a declared parent. The parser now retains requested event judgments individually while preserving the raw responses and explicitly marking missing/invalid parent-order fields unresolved. It does not turn a malformed field into a passing chronology judgment. Parser recovery does not certify the semantic judgments. Exhausted artifacts can be replayed through a corrected parser without opening a fresh repair allowance; all earlier generated repairs remain in the request log.

A post-hoc inspection found that the northern model's Blackfish-recruitment definition includes the name "Edmure Tully," whereas "Edmure" is absent from its entire frozen packet. Its own source audit nevertheless labels the claim supported. A generic parenthetical-name coverage scan records this discrepancy, flags the affected diagram node, and leaves the frozen model unchanged. Literal absence is not itself a complete entailment test or proof of an alternative identity. This is a concrete warning about same-model self-review, not a fabricated human judgment or an independently sampled error-rate estimate.

## Final explanation failures and robustness allocation

The final trace-only prose audit includes deterministic number/path checks as well as complete verbatim sentence coverage. Earlier same-model judgments could label prose supported even when the structured field literally read "baseline OR full", or a path contribution was misdescribed as a contribution of each event. A bounded prose-only repair retained the original text and audits under `application_before_prose_repair`; it changed no graph, equation, background, query or attribution. The final audit rejected all four retained explanations. Some audit outputs also quoted their own instructions as if those instructions occurred in the explanation. These are recorded failures, not silently discarded claims. Failed prose is withheld; numerical traces and failure reports remain available.

After the core construction, baselines, source critique and numerical refinement finished, the predeclared balanced 12-SCM controlled subset received the remaining seed allowance. Each new record passes a worst-case output-token budget gate, including a reserve for concurrent streams and final audit recovery. Primary held-out prompts and comparisons remain frozen at seed 2027. Application source protocols were exploratory, and the accepted alternatives provide only one distinct functional signature per case; they are not an independent three-seed application experiment. The optional second model and explorer remain deferred.
